================================================================
1. What this is
================================================================

Two mods merged into one window:

  · More Switches  - 16 client/server quality-of-life toggles
  · Tracker        - 12 entity / drop / world-state trackers
  · Free GUI scale - continuous GUI scaling (since 1.1.0)
  · Health bar     - bar and numbers above creatures (since 1.2.0)

One key, J, opens one window; four tabs at the top switch between them.


================================================================
2. Which file to download
================================================================

Check your game version and loader, then install exactly one jar:

  Game        Loader             File
  --------------------------------------------------------------------------
  1.21.1      NeoForge 21.1.x    moreswitchtracker-neoforge-1.21.1-1.2.5.jar
  26.3        NeoForge           moreswitchtracker-neoforge-26.3-1.2.5.jar
  26.3        Fabric             moreswitchtracker-fabric-26.3-1.2.5.jar

Only one may sit in a mods folder. Two of them will fail to start.


================================================================
3. Installing
================================================================

1. Install the matching Minecraft version and loader.
2. Drop the jar into .minecraft/mods (or the instance's mods folder).
3. Start the game and press J.

Installing on both client and server is recommended: legacy tracking, cross-dimension
player positions, wandering traders, persistent mobs, lag sources, mob ESP and aggro
lines involve server-side logic. Client-only features (window lock, particles, sounds,
light overlay, free GUI scale, health bar) work with a client-only install.

4. The four tabs
================================================================

[ Switches ] [ Tracker ] [ Free GUI scale ] [ Health bar ]      [ Language: Auto ]
--------------------------------------------------------------------------------
                        contents of the current tab
--------------------------------------------------------------------------------
                  Press J to open or close this window
                                [ Done ]

· J opens and closes; the window does not pause single-player
· The language button cycles Auto -> 中文 -> English; only this mod's text changes
· One switch per feature, saved immediately
· Scroll wheel scrolls the list


================================================================
5. Free GUI scale (1.1.0)
================================================================

Replaces vanilla's four integer steps with anything from 0.5x to 8x.

  · Slider: 0.05x steps, commits when you release
  · Vanilla presets: Vanilla / 1x / 2x / 3x / 4x
  · Manual input: decimals such as 1.75, then Apply
  · The cap is derived from the window size, keeping at least a 320x180 GUI

"Vanilla" hands sizing back to the game. The scale is saved and restored on launch.

Note: fractional scales put glyphs on fractional pixels, so text edges look slightly
softer. Use an integer step if sharpness matters more than size.


================================================================
6. Health bar (1.2.0)
================================================================

A red bar with "current/max" above every creature.

  · Show: Both / Bar only / Numbers only / Off
  · Size: Large / Medium / Small, scaling bar and text together
  · Categories: Monsters / Villagers / Golems / Animals, each switchable

The bar has a fixed size in blocks, so it shrinks with distance; range 48 blocks,
at most 48 bars at once. Drawn on the HUD, so it never stutters. Off by default.

================================================================
9. Tracker commands
================================================================

/tracker show <id>            re-highlight a death point
/tracker hide                 stop highlighting the current death point
/tracker list                 list recorded death points
/tracker trader <uuid>        highlight a specific wandering trader
/tracker lag [id]             list / highlight lag hotspots
/tracker sound                preview the trader chime
/tracker elite [uuid]         list / highlight elite mobs
/tracker gateway              search for an end gateway
/tracker coord                show and restore saved coordinates
/tracker coord <x> <y> <z>    set coordinates and enable (supports ~)
/tracker coord off            stop highlighting, keep the coordinates
/tracker coord clear          clear the coordinates

Coordinates and ids printed in chat are clickable.


================================================================
10. Config files
================================================================

Two files under config/, independent of each other:

  config/moreswitches.json    the 16 toggles + language + free scale + health bar
  config/tracker.json         the 12 trackers + custom coordinates

Upgrading keeps your settings; no migration needed. Delete a file to restore defaults.

The health bar section looks like this:

  "healthBar": {
    "display": "both",        // off / bar / numbers / both
    "size": "medium",         // small / medium / large
    "monsters": true,
    "villagers": true,
    "golems": true,
    "animals": true
  }


================================================================
11. FAQ
================================================================

Q: J does nothing.
A: Check the key bindings screen; another mod may have taken it.

Q: No health bars.
A: They are off by default. Press J, open the Health bar tab, set Show to Both.

Q: The GUI is too big or too small.
A: J -> Free GUI scale. Use an integer step if the text looks soft.

Q: Trackers do nothing.
A: Tracking features need the mod on the server as well.

Q: The game freezes.
A: Since 1.2.5 a watchdog dumps all thread stacks into logs/latest.log if the frame
   callback stops for 8 seconds; send that section. A known cause is the SwiftMap mod
   blocking the render thread while chunks generate; that is unrelated to this mod.
