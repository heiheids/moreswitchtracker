================================================================
一、这个模组做什么
================================================================

把两个模组合并成一个窗口：

  · 更多开关功能 —— 16 个客户端 / 服务端实用开关
  · 追踪器       —— 12 个实体、掉落物、状态追踪功能
  · 自由界面     —— 无级调整界面尺寸（1.1.0 新增）
  · 血条         —— 生物头顶显示血条和血量（1.2.0 新增）
  · 更多自定义   —— 高对比度方块开关 + 描边颜色（1.2.7 新增）

合并后只保留 J 一个按键，打开同一个窗口，用顶部五个选项卡切换。


================================================================
二、下载哪个文件
================================================================

先看你的游戏版本和加载器，只放对应的那一个 jar：

  游戏版本   加载器             文件名
  --------------------------------------------------------------------------
  1.21.1     NeoForge 21.1.x    moreswitchtracker-neoforge-1.21.1-1.2.7.jar（原版无此功能，由模组自行绘制）
  26.3       NeoForge           moreswitchtracker-neoforge-26.3-1.2.7.jar
  26.3       Fabric             moreswitchtracker-fabric-26.3-1.2.7.jar

同一个 mods 文件夹里只能放一个，放两个会启动失败。


================================================================
三、安装
================================================================

1. 装好对应的 Minecraft 版本和加载器。
2. 把 jar 放进 .minecraft/mods（整合包则放进实例的 mods 文件夹）。
3. 启动游戏，按 J。

客户端和服务端都建议安装。遗产追踪、玩家跨区位置、流浪商人、不消失怪物、
卡顿源头、怪物透视、仇恨射线等功能带服务端逻辑；只装客户端时这些会退化。
纯客户端功能（窗口锁定、粒子、声音、光照、自由界面、血条）只装客户端就能用。

================================================================
五、自由界面（1.1.0）
================================================================

把原版四档整数倍率（1×～4×）放开成 0.5×～8× 的无级调整。

  · 拖动滑块：步长 0.05×，松手才生效
  · 原版档位：原版 / 1× / 2× / 3× / 4×
  · 手动输入：支持 1.75 这种小数，点「应用」
  · 上限按窗口尺寸自动计算，保证界面至少 320×180

点「原版」把尺寸决定权交回游戏设置。倍率会保存，下次启动自动恢复。

注意：非整数倍率下文字边缘会略软，这是所有非整数缩放的固有代价。
在意清晰度就用 1×/2×/3×/4× 这类整数档位。


================================================================
六、血条（1.2.0）
================================================================

生物头顶显示一条红色血条，上方写「当前血量/总血量」。

  · 显示内容：全部显示 / 仅血条 / 仅数字 / 关闭
  · 尺寸：大 / 中 / 小，血条和文字一起缩放
  · 分类：怪物 / 村民 / 傀儡 / 动物，四类独立开关

血条有固定的世界尺寸，所以远处小、近处大；范围 48 格，同屏最多 48 个。
画在 HUD 上，不随距离抖动。默认关闭。


================================================================
七、更多自定义（1.2.7）
================================================================

  页面是一行一个设置的紧凑布局：左边标题，右边控件，都在同一个方框里。

  · 高对比度方块：就是原版「辅助功能」里的「高对比度方块轮廓」，
    被瞄准的方块会画出加粗黑边和一条彩色描边。
    这里的开关和原版是同一个开关，在哪边改都会同步，设好立即写入 options.txt。
  · 描边颜色：原版高对比度色 / 黄绿色 / 橘色 / 紫色，四个色块排成一行。
    只替换那条彩色细线，黑色衬边始终保留，所以浅色也依然醒目。
    选了原版色就不做任何替换。

色块不写文字，鼠标悬停会显示颜色名称；开关关着时，提示会一起显示在悬停提示里。

================================================================

 7 折跃门追踪器          标记最近的末地折跃门
 8 村民兴趣点追踪        村民到床 / 工作方块的连线

十、追踪器指令
================================================================

/tracker show <id>            重新高亮某个死亡点
/tracker hide                 关闭当前死亡点高亮
/tracker list                 列出记录的死亡点
/tracker trader <uuid>        高亮指定流浪商人
/tracker lag [id]             列出 / 高亮卡顿热点
/tracker sound                试听商人提示音
/tracker elite [uuid]         列出 / 高亮精英怪
/tracker gateway              搜索末地折跃门
/tracker coord                查看并恢复已保存坐标
/tracker coord <x> <y> <z>    设置坐标并自动开启（支持 ~）
/tracker coord off            关闭高亮，保留坐标
/tracker coord clear          清除坐标

聊天里的坐标和编号可以直接点击执行。


================================================================
十一、配置文件
================================================================

两个文件都在 config/ 下，互不干扰：

  config/moreswitches.json    16 个开关 + 语言 + 自由界面倍率 + 血条设置
  config/tracker.json         12 个追踪开关 + 自定义坐标

从旧版升级时原有状态会继续使用，不需要迁移。
删掉对应文件即可恢复该部分默认值。

血条设置长这样：

  "healthBar": {
    "display": "both",        // off / bar / numbers / both
    "size": "medium",         // small / medium / large
    "monsters": true,
    "villagers": true,
    "golems": true,
    "animals": true
  }


================================================================
十二、常见问题
================================================================

Q: 按 J 没反应？
A: 检查按键设置里「打开设置界面」是否被别的模组占用。

Q: 血条不显示？
A: 血条默认关闭。打开 J → 血条选项卡，把「显示内容」改成「全部显示」。

Q: 界面太大 / 太小？
A: J → 自由界面，拖滑块或点档位。嫌字糊就用整数倍率。

Q: 装了但追踪功能没反应？
A: 追踪类功能需要服务端也装本模组。

Q: 游戏卡死无响应？
A: 1.2.5 起内置卡顿自检：帧回调停 8 秒会把所有线程栈写进 logs/latest.log，
   把那一段发出来即可定位。已知迅捷地图（swiftmap）在区块生成高峰时会
   阻塞渲染线程，与本模组无关。
